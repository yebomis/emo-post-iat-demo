# EMO Post SC-IAT Demo

A shortened, public demonstration of the post-interaction Single-Category Implicit Association Test interface used in the EMO HRI study.

## Scope

- Visitors choose one of four dimensions: Agency, Experience, Moral Agency, or Moral Patiency.
- Each demonstration contains two 12-trial blocks with reversed AI-category pairings.
- Responses remain in the browser and are not saved or transmitted.
- The summary is illustrative only and does not calculate or report a research D-score.

This public demo is intentionally shorter than the study protocol and is not a psychological assessment.
